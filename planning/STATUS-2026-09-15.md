# Project status, 15 September 2026

A dated snapshot; the package has since been renamed hyperannotatR and moved
on. As of 2026-09-15, annotatR was at commit `2ad5478` on a clean `main` branch
synchronized with `origin/main`. The package version declared in `DESCRIPTION`
was `0.2.0`.

## Validation

- The full suite ran 381 tests with 1,647 passing expectations, 0 failures,
  0 errors, 0 warnings, and 2 named skips.
- The browser and loopback control lanes passed.
- The local Cubert/CUVIS and real TIVITA lanes passed when their local fixtures
  and SDK were available.
- Package build, pkgdown, and tests-only coverage (88.87%) passed.
- `R CMD check --as-cran` has one incoming-feasibility error caused by the
  package-name collision with Bioconductor's `annotatr`; substantive checks
  reported 0 warnings and 0 notes.

Detailed commands and results are recorded in
[evidence/2026-09-15/README.md](evidence/2026-09-15/README.md).

## Capability state

- I0 file interchange and I1 public R API are supported.
- I2 loopback control and I3 embedded app support are implemented and locally
  tested, but remain planned until a real qupflowR client qualification is
  recorded.
- ENVI, TIVITA, and TIFF are available in the current environment.
- Cubert is available through the local CUVIS SDK but remains unqualified.
- OME-TIFF is unavailable because `RBioFormats` is not installed.

Reproducible analytical summaries

This example follows persisted annotations through masks, raw pixel records, ROI spectra, image summaries, and agreement tables. It uses the small synthetic reference bundle in the source repository at tests/testthat/fixtures/analytical/. Its NumPy generator computes the numerical reference independently of annotatR. The workflow never reads the expected JSON to calculate its results; the regression test uses that JSON only for comparison.

The example functions are installed at examples/reproducible-analysis.R. They are reusable source code, not exported package APIs. The fixture bundle is kept in the repository tests rather than duplicated in the installed package. To reproduce this vignette, use a source checkout with the reviewed package code installed, or use pkgload::load_all() from that checkout first. Run the following code from the repository root (the vignette build uses the equivalent relative path from its own directory).

source(system.file("examples", "reproducible-analysis.R", package = "annotatR"))
fixture_dir <- normalizePath("tests/testthat/fixtures/analytical")

Create the input once, then reopen it for every analysis. The synthetic entry ID is analytical-image-001; the two imported ROI IDs are preserved. Revision zero is an explicit metadata value, not a new revision generated by each analysis. For an adapted study, retain its actual entry IDs and increment the persisted annotation_revision whenever annotations change. Reimporting annotations into a fresh project for every run would obscure that history.

work <- tempfile("analytical-example-")
dir.create(work)
project_path <- file.path(work, "annotations.rds")
prepare_analytical_example(fixture_dir, project_path)
first <- run_analytical_example(project_path, fixture_dir, file.path(work, "first"))
second <- run_analytical_example(project_path, fixture_dir, file.path(work, "second"))
stopifnot(identical(first, second))
files <- list.files(file.path(work, "first"))
stopifnot(identical(
  unname(tools::md5sum(file.path(work, "first", files))),
  unname(tools::md5sum(file.path(work, "second", files)))
))

Both functions refuse to overwrite existing outputs. The analysis does not save or mutate its input project. The ten CSV tables and settings.json are deterministic for the same persisted input and software environment. Source paths, signatures, input hashes and software versions deliberately remain in the settings; relocating files or changing software can change provenance. No run timestamp or runtime cache/read-generation identity enters these outputs. The saved project’s own historical timestamps remain in that input file and therefore in its checksum. Optional execution timestamps belong in a separate run log, not in a result table or its deterministic configuration.

Nonfinite values and spectra

at_extract(..., stat="all", nonfinite="omit") and at_extract_spectrum(..., nonfinite="omit") choose finite-only statistics explicitly. n_px and the statistic n still mean selected support. n_valid counts finite contributors; n_invalid counts selected NA, NaN and infinite values. Sample SD uses denominator n_valid - 1; it is undefined for a singleton. All-invalid summaries, including sum, are NA. Empty selections have zero contributors; the example retains an image-band row with NA statistics.

The raw pixel API retains nonfinite samples. There are four unique invalid pixel-band values but five invalid ROI-pixel-band records, because the positive infinity in the overlap belongs to both ROIs. The raw tables include sample_status (finite, NA, NaN, +Inf, -Inf) to preserve distinctions that CSV missing-value serialization could collapse. The four unselected background cells are a spatial exclusion, separate from invalid selected samples. n_excluded_rois counts ROIs with no selected cells; it is zero here. The example applies no ROI or label filters.

This workflow produces numerical spectra and tables. It generates no image preview. Display normalization for the mixed NaN/Inf RGB fixture remains outside this qualification; no RGB or native ImageMagick success is claimed.

Agreement with explicit alignment

The separate 3 by 4 categorical and bitfield NPY cases exercise agreement; these are not prediction masks for the 4 by 5 cube. The independent fixture generator declares their common row/column grids. Since arrays alone cannot prove source registration, this example uses alignment="assert" and records that basis. For study masks with durable common source/grid metadata, use alignment="check" to verify it. Equal dimensions alone are not evidence of registration, and assertion never resamples mismatched grids.

at_read_npy() receives explicit encoding, background and label codebooks. Ordinary comparisons use code_alignment="strict". The deliberately swapped categorical codes use code_alignment="by-label", preserving original codebooks in settings. An absent class remains a table row with undefined Dice/IoU, and macro means exclude such undefined rows.

Traceability and scope

settings.json accompanies the tables with the persisted entry/ROI IDs and revision, durable source descriptor and reader options, MD5 hashes of the project and all eight data inputs (including the ENVI payload), calibration, band coordinates/units, extraction and rasterization settings, mask codebook, both sides’ validated agreement metadata/codebooks, estimands, and count definitions. It records the actual R and dependency versions and sf external library versions. The ENVI backend is implemented by annotatR, whose version is recorded; separately unavailable plugin-version metadata is explicitly "unknown". MD5 checks exact-byte integrity, not authenticity. The source tree or build artifact used for a study should also be archived with these outputs.

This is a descriptive example for one image and two overlapping ROIs. Pixels, bands and ROI means are not independent image replicates. Inferential uncertainty requires the study’s independent sampling unit (for example a donor, specimen or image, as justified by its design), with nesting and overlap handled explicitly. There is no resampling here and the recorded seed is null. Any added resampling must declare its seed and independent unit. No model training or clinical claim is part of this example.

The implementation retains existing extraction memory bounds: one bounding-box tile per ROI, a max_px=1e6 raw extraction guard, and in-memory deduplication and tables. It is a small synthetic workflow, not a streaming analysis engine or whole-slide resource qualification.

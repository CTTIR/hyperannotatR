# Number of ROIs in a layer

Number of ROIs in a layer

## Usage

``` r
at_layer_n(layer, call = rlang::caller_env())
```

## Arguments

- layer:

  An
  [annot_layer](https://cttir.github.io/hyperannotatR/reference/hyperannotatR-classes.md).

- call:

  The calling environment, for error reporting.

## Value

An integer scalar.

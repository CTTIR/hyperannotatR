# Get a registered backend

Get a registered backend

## Usage

``` r
at_backend_get(name, call = rlang::caller_env())
```

## Arguments

- name:

  Single string backend name.

- call:

  The calling environment, for error reporting.

## Value

The `annot_backend` object.

# Overlay a mask on the canvas

Overlay a mask on the canvas

## Usage

``` r
at_canvas_set_overlay(proxy, mask, alpha = 0.5, call = rlang::caller_env())
```

## Arguments

- proxy:

  An `atcanvas_proxy`.

- mask:

  An `annot_mask`.

- alpha:

  Overlay opacity. Default `0.5`.

- call:

  The calling environment, for error reporting.

## Value

The proxy, invisibly.

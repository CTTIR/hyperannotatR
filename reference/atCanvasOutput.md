# Shiny output for the annotation canvas

Shiny output for the annotation canvas

## Usage

``` r
atCanvasOutput(outputId, width = "100%", height = "600px")
```

## Arguments

- outputId:

  Output id.

- width, height:

  Output dimensions.

## Value

A Shiny output element.

# Set the active drawing tool

Set the active drawing tool

## Usage

``` r
at_canvas_set_tool(proxy, tool, call = rlang::caller_env())
```

## Arguments

- proxy:

  An `atcanvas_proxy`.

- tool:

  One of the canvas tools.

- call:

  The calling environment, for error reporting.

## Value

The proxy, invisibly.

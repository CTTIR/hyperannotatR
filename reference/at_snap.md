# Snap ROI vertices to a grid

Snap ROI vertices to a grid

## Usage

``` r
at_snap(roi, grid = 1, call = rlang::caller_env())
```

## Arguments

- roi:

  An
  [annot_roi](https://cttir.github.io/hyperannotatR/reference/hyperannotatR-classes.md).

- grid:

  Positive numeric grid spacing in pixels. Default `1`.

- call:

  The calling environment, for error reporting.

## Value

An
[annot_roi](https://cttir.github.io/hyperannotatR/reference/hyperannotatR-classes.md)
with vertices rounded to the nearest grid multiple. A geometry that
snapping makes invalid (e.g. a collapsed ring) is repaired with a
warning.

## Examples

``` r
at_snap(at_roi_point(3.4, 5.6, label = "a"), grid = 1)
#> <annot_roi> a (POINT)
#> id: "roi_000000090"  |  level: 0  |  source: manual
#> bbox: [3, 6] - [3, 6]
```

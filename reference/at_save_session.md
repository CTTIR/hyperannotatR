# Save a session

Save a session

## Usage

``` r
at_save_session(
  session,
  path = NULL,
  overwrite = FALSE,
  call = rlang::caller_env()
)
```

## Arguments

- session:

  An
  [annot_session](https://cttir.github.io/hyperannotatR/reference/hyperannotatR-classes.md).

- path:

  Optional output path; defaults to `_session.rds` in `out_dir`.

- overwrite:

  Logical; overwrite an existing file. Default `FALSE`.

- call:

  The calling environment, for error reporting.

## Value

The session, invisibly.

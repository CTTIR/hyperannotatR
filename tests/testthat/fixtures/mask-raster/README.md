# Independent grayscale mask fixtures

Synthetic PNG bytes are generated by `python3 generate.py` using only Python's
standard library (`struct`, `zlib` and `hashlib`), independently of R, magick
and hyperannotatR. `SHA256SUMS` records all 20 PNGs. Tests read these committed bytes;
no Python installation, network access or private files are needed at test time.

`gray16.png` stores rows `[0,1,255,256]`, `[4096,32767,32768,65535]` at unsigned
16-bit depth. Three counterparts add gAMA 20000, 100000 and 220000. `gray8.png`
stores `[0,1,9,10]`, `[13,32,128,255]`. `whitespace8.png` starts with a literal
10 and includes 13, 32, 9 and 35, exposing binary-header whitespace/comment
misinterpretation. Both depths include zero, binary 0/1 and maximum-extrema
arrays. RGB, RGBA, gray-alpha and palette and 1-bit grayscale files exercise explicit rejection.

The writer check in `tests/qualification/mask-raster-exports.R` emits normal
and absent-tiff adapter outputs. Its adjacent Python verifier independently
checks TIFF depth/type/raw rows with tifffile and PNG CRC, IHDR and raw rows
with a standard-library scanline decoder. Example from the package root:

```sh
Rscript tests/qualification/mask-raster-exports.R /tmp/annotatr-mask-exports
uv run --with tifffile==2026.9.9 --with numpy==2.5.3 --with imagecodecs python tests/qualification/mask-raster-exports.py /tmp/annotatr-mask-exports
```

This qualifies internal 16-bit PNG transport; public PNG export remains 8-bit
only. Public PNG input supports both 8-bit and 16-bit grayscale.

Review regression fixtures `gray8-trns.png` and `gray16-trns.png` declare a
transparent sample with a tRNS chunk while retaining IHDR grayscale colour
type 0. Their rows are `[0,1,255]` with transparent code 1 and `[0,256,65535]`
with transparent code 256. `gray16-trns-unused.png` uses the latter row but
marks unused code 1 transparent. All three must reject before conversion.

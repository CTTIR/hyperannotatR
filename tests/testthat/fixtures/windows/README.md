Synthetic independent OME scalar references, generated by `generate.py` using
NumPy 2.5.3 and tifffile 2026.9.9. No acquired, vendor, or private image data.
`sha256.json` pins the binary bytes. The OME UUID is fixed for reproducibility.
The two rows are written directly from the literal arrays in the generator;
tests assert their selected windows, single pixels and duplicate channels.
Integer boundaries, signed int32 minimum, unsigned32 maximum, NaN and both
infinities are intentional raw samples. These extend the T07 CYX/pyramid
fixtures, which remain unchanged.
